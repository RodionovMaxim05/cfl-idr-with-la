Detailed Description

Sparse-matrix representation of a Dyck-reachability graph.

The graph encodes parenthesis-labeled edges as separate GraphBLAS matrices. Each pair of opening / closing matrices corresponds to one parenthesis type (indexed 0 … n_par-1 for parentheses, 0 … n_bra-1 for brackets). Unlabeled edges are stored in normal.
