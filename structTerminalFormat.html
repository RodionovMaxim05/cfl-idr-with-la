Detailed Description

Interface for parsing terminal labels in CFL-reachability graphs.

Provides a pluggable strategy to classify edge labels as opening/closing parentheses or brackets. This abstraction allows the same graph parsing pipeline to support different labeling conventions (e.g., op_0/cp_0 vs (/), [/]).

A TerminalFormat instance must implement both function pointers to be usable with get_idr_graph and related parsing utilities.
